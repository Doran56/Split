Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

This app targets Expo SDK 54 specifically (not the latest SDK) because the
user's installed Expo Go client only supports SDK 54. Do not bump `expo` or
any `expo-*`/React Native ecosystem package past what SDK 54 bundles
(see `node_modules/expo/bundledNativeModules.json` for exact versions)
without confirming the user's Expo Go client supports the new SDK first.
